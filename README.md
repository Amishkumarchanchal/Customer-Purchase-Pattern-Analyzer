# Customer Purchase Pattern Analyzer 

##  About the Project
Customer Purchase Pattern Analyzer is a Python-based project that analyzes customer purchasing data using Pandas and Matplotlib.

It helps understand monthly spending patterns, category-wise expenses, total spending, and customer purchase statistics through data analysis and visualization.

##  Features
- Monthly Spending Analysis
- Total Customer Spending
- Best Performing Month
- Category-wise Spending Analysis
- Category-wise Spending Percentage
- Mean and Median Purchase Calculation
- Total Number of Orders
- Monthly Spending Visualization using Bar Chart

##  Technologies Used
- Python
- Pandas
- Matplotlib
- CSV Dataset

##  Installation & Setup

**Step 1: Clone the Repository**
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the Project Folder**
```bash
cd Customer-Purchase-Pattern-Analyzer
```

**Step 3: Install Required Libraries**
```bash
pip install pandas matplotlib
```

**Step 4: Run the Project**
```bash
python main.py
```

##  How It Works
1. Loads customer order data from a CSV file.
2. Validates and processes the dataset.
3. Calculates monthly and category-wise spending.
4. Generates purchase statistics.
5. Displays a monthly spending chart.

##  Project Objective
The main objective of this project is to learn Python data analysis, data manipulation, and data visualization using real-world structured data.
